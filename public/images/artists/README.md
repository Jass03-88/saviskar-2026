## 🎨 Image Specifications for Drop-In Replacements

To update an artist's image:
1. **Aspect Ratio**: 3:2 or 16:9 landscape (Recommended: **1200 × 800 pixels** or **1920 × 1080 pixels**).
2. **Format**: Modern **WebP** (`.webp`) format for instant loading with zero lag.
3. **Max File Size**: Capped under **180 KB** per image.
4. **Replacement Workflow**:
   - Simply drop the new image into this directory using the exact filename specified above.
   - Or, override the image URL directly in [`data/artistsPlaceholderConfig.ts`](file:///Users/madhavvashisht/Desktop/MY_Projects/Saviskar26/data/artistsPlaceholderConfig.ts).
